# Group Hello World

Prints a greeting followed by our group members.

```
python hello.py
```

## Adding your name

1. `git pull` on `main`, then `git checkout -b add-<yourname>`
2. Add your name as its own line inside the `members` list in `hello.py`:
   ```python
   members = [
       "Your Name",
   ]
   ```
3. Run `python hello.py` to check it works.
4. Commit, `git push -u origin add-<yourname>`, and open a pull request.
5. Ask a teammate to review and approve it, then merge.
